# Playwright 심사 에이전트 전용 테스트 시나리오 가이드

---

## 🤖 Playwright 에이전트 검증 가이드 (34% 배점 완주 가이드)

이 문서는 해커톤 심사 에이전트(Playwright)가 PartyQuest 라이브 서비스 URL에 접속하여 핵심 시나리오를 에러 없이 100% 완주할 수 있도록 설계된 시나리오 가이드입니다.

---

## 📍 3단계 핵심 시나리오 (Core Scenario)

### Step 1. 온보딩 및 파티 룸 간편 입장 (3초 입장)
1. 메인 URL 접속 후 모달 내 **닉네임 입력 필드**에 닉네임(예: `AI_Judge`) 입력
2. **[파티 퀘스트 입장하기]** 버튼 클릭
3. 상단 헤더에 닉네임과 `0 P` 포인트 뱃지 표시 확인

### Step 2. 파티 퀘스트 수행 및 포인트 적립
1. **[🎯 퀘스트 목록]** 탭에서 미션 카드 확인
2. **"스낵바에서 음료 받고 호스트와 하이파이브! 🍹"** 카드의 **[미션 완료 인증하기]** 버튼 클릭
3. 화면에 **Confetti 폭죽 효과** 및 **퀘스트 완수 성공 모달** 팝업 확인 (`+50 P` 획득)
4. 상단 헤더 포인트가 `50 P`로 즉시 업데이트되는지 확인

### Step 3. 리더보드 랭킹 & 리워드 쿠폰 교환
1. **[🏆 실시간 랭킹]** 탭 클릭 ➔ 내 랭킹 및 상위 참가자 랭킹 확인
2. **[🎁 리워드 교환]** 탭 클릭 ➔ 보유 포인트에 맞는 리워드 선택 후 **[교환하기]** 클릭
3. **모바일 쿠폰/바코드 팝업 모달** 발급 완료 확인
