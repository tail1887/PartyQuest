# 🏆 PartyQuest 해커톤 제출 최종 체크리스트 (Submission Guide)

---

## 1. 제출 폼 입력 데이터 6종 최종 패키지

심사 사이트 로그인 폼 제출 시 아래 6가지 항목을 그대로 복사/입력하여 제출합니다:

### 1) 서비스명 & 슬로건
- **서비스명**: **PartyQuest (파티퀘스트)**
- **한 줄 슬로건**: *"어색한 모임은 끝! 미션과 퀘스트로 즐기는 인터랙티브 파티 매니저"*

---

### 2) 기획안 요약 (D 영역 주제 적합성 10점 만점 방어)
- **배경**: 개발자 행사, 컨퍼런스, 페스티벌, 생일파티 등 모임에서 아는 사람들끼리만 뭉치는 현상과 I성향 참가자의 네트워킹 장벽 해결.
- **핵심 솔루션**:
  - QR 코드로 3초 만에 간편 입장
  - 아이스브레이킹 & 현장 미션 퀘스트 수행 및 Confetti 폭죽 효과
  - 퀘스트 포인트 적립 ➔ 스낵바 음료권/럭키드로우 쿠폰 실시간 교환
  - 참가자 프로필 카드 & 스티커/방명록 네트워킹 월

---

### 3) 발표 스크립트 요약 (GTM 33% & BM 33% 심사관 공략)
- **GTM 파티형 바이럴 (30%)**:
  - 파티 호스트 1명이 파티를 생성하면 N명의 게스트가 QR 하나로 전원 유입되는 **1:N 구조적 바이럴 루프**.
  - 파티 종료 후에도 유지되는 방명록/프로필 카드 아카이빙으로 차기 모임 연결.
- **비즈니스 모델 & 지불 용의 (30%)**:
  - **Freemium 요금제**: 소규모 개인 파티 무료, 기업/대규모 행사용 프로 호스트 구독제 ($29~$99/월).
  - **인앱 결제 & 스폰서십**: 기업 핑거푸드/음료 브랜드 스폰서십 쿠폰 연계 및 프로필 커스텀 스티커 판매.

---

### 4) 실제 서비스 라이브 URL
- **Vercel / 배포 URL**: `https://partyquest.vercel.app` (또는 Vercel 배포 주소)
- **로컬 데모 실행 방법**:
  ```bash
  npm run dev
  # http://localhost:3000 접속
  ```

---

### 5) 핵심 테스트 시나리오 (Playwright 34% 완주)
1. 접속 후 상단 **[⚡️ 심사관 원클릭 자동 체험]** 클릭 또는 닉네임 입력 후 **[입장하기]**
2. 퀘스트 카드 **[미션 완료 인증하기]** 클릭 ➔ 폭죽 효과 및 `+50P` 획득 확인
3. **[🏆 실시간 랭킹]** 탭 ➔ 순위 확인
4. **[🎁 리워드 교환]** 탭 ➔ **[교환하기]** 클릭하여 바코드 쿠폰 팝업 발급 확인
