# MVP 스코프 및 기술/개발 전략 회의 분석

---

## 1. 핵심 개발 전략: **초고속 MVP 배포 우선 (Fast-Prototype First)**

팀 회의를 통해 복잡도를 줄이고 심사 에이전트(Playwright) 완주율을 극대화하기 위해 다음 개발 전략을 확정함:

1. **호스트 복잡도 축소**:
   - 초기 MVP에서는 복잡한 주최자 퀘스트 CRUD를 기다리지 않고, **기본 퀘스트 프리셋(Default Quest Set)**이 즉시 활성화된 상태로 제공
   - 사용자가 QR/링크로 접속하자마자 즉시 튜토리얼과 함께 퀘스트를 수행할 수 있도록 설계
2. **2단계 개발 로드맵**:
   - **Phase 1 (MVP)**: 프로토타입 UI 완성 ➔ 기본 퀘스트 수행 & 인증 ➔ 포인트/리더보드 공개 ➔ Vercel 즉시 배포
   - **Phase 2 (고도화)**: 디자인 스킨 개선(Tailwind 기반 세련된 파티 테마), 주최자 이벤트/미션 관리(CRUD), 발표 자료/HTML 패키징

---

## 2. 권장 기술 스택 (Tech Stack)

에이전트가 가장 빠르고 버그 없이 구현할 수 있으며 배포(Vercel)가 즉시 가능한 최신 모던 웹 스택:

- **프레임워크**: Next.js 14+ (App Router) 또는 React + Vite + TypeScript
- **스타일링**: Tailwind CSS + Lucide React (아이콘) + Framer Motion (파티 인터랙션 애니메이션)
- **상태/데이터**: 로컬 스토리지 기반 상태 관리 (서버 부하/DB 지연 없이 Playwright가 즉각 완주 가능) + 필요 시 Supabase 연동
- **배포**: Vercel (원클릭 배포 및 실시간 안정성 확보)

## 3. 심사관(Playwright) 최적화 핵심 플로우

```text
[1. QR / 랜딩 접속]
  - 닉네임 입력 & 파티 입장 (원클릭)
        ↓
[2. 파티 퀘스트 목록 확인]
  - "오늘 처음 만난 사람과 공통점 2개 찾기" 등 인터랙티브 미션 확인
        ↓
[3. 퀘스트 수행 및 완료 체크]
  - 미션 완료 버튼 클릭 / 키워드 입력 ➔ 포인트 획득 애니메이션
        ↓
[4. 실시간 리더보드 & 보상 수령]
  - 랭킹 확인 및 스낵/음료 교환권 획득 화면 확인
```
